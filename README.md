## Tasks
### 1task.cpp
Create an n x n matrix and fill it with random integers from -20 to 20. Output the matrix to the screen and to matrix.txt.
Sort:
 - each row of the matrix in descending order using the bubble sort, output the matrix to matrix1.txt;
 - each column of the matrix in ascending order using the selection sort, output the matrix to matrix2.txt;
 - the diagonals of the matrix parallel to the main diagonal, in descending order using the insertion sort, output the matrix to matrix3.txt;
 - the diagonals of the matrix parallel to the secondary diagonal, in ascending order using the Shell sort, output the matrix to matrix4.txt;
### 2task.cpp
Generate a sequence of 10,000 integers from 1 to 10,000.
Sort it using the following algorithms:
 - Bubble sort.
 - Insertion sort.
 - Selection sort.
 - Shell sort.
Display the time it took to sort this array using each algorithm.
